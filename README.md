# 🧪 PROJECTS


1) My Pawfect — AI Pet Nutrition
   
Type: AI Product Strategy • MVP Definition • CX/Operations Design

Problem
Pet owners need vet-aligned, personalized meal plans; existing options are generic and hard to maintain.

Users
New/busy pet parents; health-conscious owners; future “vet-mode” for professionals.

Solution
A subscription platform with a vet-modeled AI meal planner that creates diet plans from pet profile + medical inputs, with predictive dietary logic, inventory sync, and smart routing.

Key Features (MVP → Growth)

Onboarding wizard → AI meal plan generation → tiered subscription

Inventory & recommendations → checkout → order tracking

Later: multi-pet, loyalty, seasonal bundles, role-based access

Tech & Ops (Conceptual)

AI/ML: rules + lightweight models for plan selection & substitution

Data: pet profile, breed/age, activity, medical constraints

Ops: real-time inventory, delivery windows, exception handling

Metrics/KPIs
Activation rate, first plan time (TTFP), plan adherence, churn, LTV/CAC.

Outcomes (Deck)
Clear roadmap (Q1–Q4), risk register, and cost model for a scalable launch.

3) Dmart Warehouse Automation — Program/Project Management

Type: Program Planning • Robotics Integration • PMO Controls

Problem
Manual warehouse ops → slow fulfillment, stock errors, high costs, poor scalability.

Solution
Introduce AMRs (autonomous mobile robots) + AS/RS with WMS integration; redesign floor plan, power/network, compliance, and change management.

Scope & Approach

Civil & structural upgrades, robotics paths, charging & safety zones

Electrical (transformers, UPS), industrial Wi-Fi, WMS integration

Phased plan: charter → procurement → build → integrate → test → train → go-live

Controls & Risk
Schedule/cost control, audits (quality, cyber), top-10 risks (e.g., AMR malfunction, integration failure) with mitigations.

Expected Impact
Fulfillment cost ↓ ~25%, space utilization ↑ ~30%, fewer errors, faster throughput.

5) Superstore Sales Analytics

Type: Data Analytics • Statistical Inference • BI Storytelling

Goal
Find seasonal patterns, profitability drivers, and regional performance differences.

Methods

Two-sample t-test: 2020 vs 2019 demand (significant increase)

ANOVA: category-wise profit (Technology > Furniture/Office Supplies)

ANOVA: lead time across regions (no significant difference); by category (Office Supplies longest)

Outcomes
Clear, actionable insights for resource allocation, inventory strategy, and category optimization; compelling charts for stakeholder buy-in.

Targets
Reduced cycle time, increased oil output, lower scrap/rework—tracked weekly with operator feedback loops.
